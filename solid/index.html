SOLID — خمس أسئلة مش خمس تعريفات

الـSOLID خمس قواعد بتساعدك تكتب كود أسهل في الفهم والتعديل والاختبار. المهم مش تحفظ الأسماء — المهم تعرف تسأل نفسك السؤال الصح وأنت بتصمم.

4تحذير مهم قبل ما تبدأ

SOLID مش قوانين لازم تطبّقها بالعافية

الهدف منها إن الكود يبقى أبسط وأسهل في التغيير. أحيانًا class صغيرة وif بسيطة تكون أوضح من تصميم كبير مليان interfaces وclasses.

أشهر خطأ عند المبتدئين: تطبيق كل المبادئ الخمسة على كل class من أول سطر. النتيجة مشروع فيه 40 interface وclass واحدة بتشتغل فعليًا.

الصح: اكتب أبسط حل يشتغل، ولما تحس بالألم — تعديل بيلمس أماكن كتير، test صعب تكتبه، class بيعدّلها 4 فرق — ساعتها المبدأ المناسب هيبان لوحده.
