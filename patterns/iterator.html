Iterator

افتكرها

Iterator = امشِ على العناصر من غير ما تعرف بنيتها الداخلية.

1المشكلة

// كل مجموعة ليها طريقة مختلفة للمرور
foreach ($array as $item) { }                    // array

for ($i = 0; $i < $list->count(); $i++) {        // linked list
    $item = $list->get($i);
}

$node = $tree->root();                           // شجرة
while ($node = $node->next()) { }
المشكلة

الـclient لازم يعرف بنية كل مجموعة عشان يمشي عليها. ولو غيّرت البنية الداخلية (array → linked list)، كل الكود اللي بيمشي عليها بيتكسر.

2الحل في PHP

PHP عندها الـpattern دي مبنية في اللغة نفسها — Iterator وIteratorAggregate:

class OrderCollection implements IteratorAggregate, Countable
{
    public function __construct(
        private array $orders = []
    ) {}

    public function getIterator(): Traversable
    {
        return new ArrayIterator($this->orders);
    }

    public function count(): int
    {
        return count($this->orders);
    }
}

// الاستخدام — الـclient ما يعرفش البنية الداخلية
foreach ($orders as $order) {
    echo $order->total();
}

دلوقتي تقدر تغيّر التخزين الداخلي من array لأي حاجة تانية، والـforeach هيفضل شغّال.

3الفايدة الكبرى: Generators والـlazy loading

أقوى استخدام عملي للـIterator في PHP هو الـyield:

✕ تحميل كل حاجة في الذاكرة
function readOrders(string $file): array
{
    $rows = [];

    foreach (file($file) as $line) {
        $rows[] = json_decode($line);
    }

    return $rows;    // مليون صف في الذاكرة
}
✓ Generator — سطر واحد في المرة
function readOrders(string $file): Generator
{
    $handle = fopen($file, 'r');

    while (($line = fgets($handle)) !== false) {
        yield json_decode($line);
    }

    fclose($handle);
}

// نفس الاستخدام بالظبط
foreach (readOrders('orders.jsonl') as $order) { }

نفس الـinterface، استهلاك ذاكرة مختلف تمامًا. ودي قوة الـIterator: الـclient ما اتغيّرش خالص.

4امتى تكتب Iterator بإيدك؟

في PHP نادرًا — لأن اللغة بتغطّي معظم الحالات. لكن بتحتاجه لما:

  • عايز تمشي على شجرة بترتيب معيّن (depth-first / breadth-first).
  • عايز أكتر من طريقة مرور على نفس المجموعة.
  • بتقرا من مصدر خارجي بصفحات (API pagination) وعايز تخفي التفاصيل دي.
class PaginatedApiIterator implements IteratorAggregate
{
    public function getIterator(): Generator
    {
        $page = 1;

        do {
            $response = $this->client->get("/orders?page=$page");

            foreach ($response['data'] as $item) {
                yield $item;
            }

            $page++;
        } while ($response['has_more']);
    }
}

// الـclient بيشوف قايمة واحدة، والـpagination مخفية تمامًا
foreach ($apiOrders as $order) { }

5Interview

Why Iterator?

«عشان الـclient يمشي على المجموعة من غير ما يعرف بنيتها الداخلية، فأقدر أغيّر التخزين من غير ما أكسّر الكود اللي بيستخدمها. في PHP الـpattern مبنية في اللغة عن طريق Iterator وIteratorAggregate، وأقوى استخدام ليها هو الـgenerators — بقرا مليون صف بنفس الـforeach من غير ما أحمّلهم في الذاكرة.»
