افتكرها

Memento = خُد لقطة من الحالة، ورجّعها بعدين — من غير ما تكسر الـEncapsulation.

1المشكلة

عايز تعمل undo. الحل الساذج: تخلي كل حاجة عامة عشان تقدر تقرا الحالة وترجّعها:

class Editor
{
    public string $content;      // بقت public عشان الـhistory تقدر تقراها
    public int $cursorPosition;
    public array $selection;
}

class History
{
    public function save(Editor $editor): void
    {
        $this->snapshots[] = [
            'content'  => $editor->content,
            'cursor'   => $editor->cursorPosition,
            'selection'=> $editor->selection,
        ];
    }
}
المشكلة

عشان تعمل undo، كسرت الـEncapsulation بتاعة الـEditor. وكمان الـHistory بقت عارفة بنية الـEditor الداخلية — فأي تعديل فيه بيكسّرها.

2الحل

// الـMemento — صندوق مقفول
final class EditorMemento
{
    public function __construct(
        private readonly string $content,
        private readonly int    $cursor,
    ) {}

    // بس الـEditor هو اللي بيقرا منها
    public function content(): string { return $this->content; }
    public function cursor(): int     { return $this->cursor; }
}

// الـOriginator — صاحب الحالة
class Editor
{
    private string $content = '';
    private int    $cursor  = 0;

    public function save(): EditorMemento
    {
        return new EditorMemento($this->content, $this->cursor);
    }

    public function restore(EditorMemento $memento): void
    {
        $this->content = $memento->content();
        $this->cursor  = $memento->cursor();
    }
}

// الـCaretaker — بيمسك الـmementos من غير ما يفتحها
class History
{
    private array $stack = [];

    public function push(EditorMemento $m): void { $this->stack[] = $m; }

    public function undo(): ?EditorMemento
    {
        return array_pop($this->stack);
    }
}

الاستخدام

$editor  = new Editor();
$history = new History();

$editor->type('Hello');
$history->push($editor->save());       // لقطة

$editor->type(' World');
$history->push($editor->save());       // لقطة

$editor->restore($history->undo());    // رجعنا خطوة

الفكرة الذكية

الـHistory بتمسك الـmemento وبتديه للـEditor لما يطلبه، لكنها ما تقدرش تقرا اللي جواه. الـEncapsulation اتحفظت — والـHistory مش عارفة أي حاجة عن بنية الـEditor.

4المشاكل العملية

  • الذاكرة: لقطة كاملة لكل تغيير بتاكل ذاكرة بسرعة. البديل: تخزّن الفرق بدل الحالة الكاملة.
  • الـobjects الداخلية: لو الحالة فيها objects، محتاج deep copy وإلا اللقطة هتتغيّر مع الأصل.
  • الـresources: مفيش طريقة تاخد لقطة من اتصال مفتوح أو ملف.

عشان كده في الواقع الـundo كتير بيتعمل بالـCommand — كل command بتعرف تعمل undo() لنفسها، وده أخف من حفظ الحالة كاملة.

6Interview

Why Memento?

«لما أحتاج أحفظ حالة object وأرجّعها بعدين — زي undo — من غير ما أكشف بنيته الداخلية. الـoriginator بيعمل الـmemento ويقراه، والـcaretaker بيخزّنه من غير ما يفتحه. عمليًا في تطبيقات كتير بستخدم Command مع undo بدلها، لأن حفظ الحالة كاملة كل مرة مكلف في الذاكرة.»
