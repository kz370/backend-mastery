Abstract Factory

لما تحتاج تنشئ عائلة كاملة من الـobjects المتوافقة مع بعض، من غير ما تحدد الـclasses بالاسم.

افتكرها

Factory Method بتنشئ منتج واحد. Abstract Factory بتنشئ عائلة منتجات متوافقة.

1المشكلة

عندك نظام بيدعم أكتر من مزوّد سحابي، وكل مزوّد له مجموعة خدمات لازم تشتغل مع بعض:

AWS → S3Storage + SqsQueue + SesMailer Azure → BlobStorage + ServiceBus + AzureMailer
// الحل المباشر — خطر
$storage = new S3Storage($config);
$queue   = new AzureServiceBusQueue($config);   // ← خلط بين مزودين!
$mailer  = new SesMailer($config);
المشكلة

مفيش حاجة بتمنعك تخلط بين المزوّدين. وده بيولّد أخطاء صعبة الاكتشاف: الـcredentials مش متطابقة، الـregions مختلفة، والفواتير على حسابين.

2الحل

interface CloudFactory
{
    public function storage(): Storage;
    public function queue(): Queue;
    public function mailer(): Mailer;
}

class AwsFactory implements CloudFactory
{
    public function __construct(private AwsConfig $config) {}

    public function storage(): Storage { return new S3Storage($this->config); }
    public function queue(): Queue     { return new SqsQueue($this->config); }
    public function mailer(): Mailer   { return new SesMailer($this->config); }
}

class AzureFactory implements CloudFactory
{
    public function storage(): Storage { return new BlobStorage($this->config); }
    public function queue(): Queue     { return new ServiceBusQueue($this->config); }
    public function mailer(): Mailer   { return new AzureMailer($this->config); }
}

// الاستخدام — مستحيل تخلط
class App
{
    public function __construct(private CloudFactory $cloud) {}

    public function run(): void
    {
        $this->cloud->storage()->put('file.txt', $data);
        $this->cloud->queue()->push($job);
    }
}

دلوقتي اختيار المزوّد بيحصل مرة واحدة عند إنشاء الـfactory، وكل الخدمات بتيجي من نفس العائلة تلقائيًا.

3الهيكل

CloudFactory (abstract factory) ├── AwsFactory → S3Storage · SqsQueue · SesMailer └── AzureFactory → BlobStorage · ServiceBusQueue · AzureMailer Storage (abstract product) ← S3Storage / BlobStorage Queue (abstract product) ← SqsQueue / ServiceBusQueue Mailer (abstract product) ← SesMailer / AzureMailer

5امتى ما تستخدموش

التكلفة عالية

إضافة منتج جديد للعائلة (مثلًا cache()) معناها تعديل كل الـfactories الموجودة. يعني الـpattern دي:

  • ✅ مفتوحة لإضافة عائلة جديدة (Google Cloud) بسهولة.
  • ❌ مقفولة ضد إضافة منتج جديد للعائلة — بيكسّر كل الـimplementations.

فما تستخدمهاش إلا لما تكون العائلات ثابتة نسبيًا والمنتجات معروفة.

6Interview

Why Abstract Factory?

«لما يكون عندي مجموعة منتجات لازم تشتغل مع بعض من نفس العائلة — زي خدمات مزوّد سحابي واحد. الـAbstract Factory بتضمن إن كل الـobjects اللي بتتعمل من نفس العائلة، فمستحيل أخلط بين مزوّدين بالغلط. الفرق عن الـFactory Method إن دي بتنشئ منتج واحد، والـAbstract Factory بتنشئ عائلة.»
